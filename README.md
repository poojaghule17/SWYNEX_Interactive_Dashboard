# SWYNEX Interactive Dashboard

## Task 3 – Interactive Sales Dashboard

This project presents an interactive sales dashboard created using Microsoft Power BI.

## Dashboard Features

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Sales by Category
- Sales by Region
- Profit by Category
- Monthly Sales Trend
- Region Filter
- Category Filter

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization

## Objective

The objective of this dashboard is to analyze sales performance and present key business insights using interactive visualizations and filters.

## Deliverable

Interactive Power BI dashboard created as part of the SWYNEX Task 3
